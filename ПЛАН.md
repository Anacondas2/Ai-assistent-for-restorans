# ИИ-агент для ресторанов Гамбурга — План проекта

> Документ-«точка правды». Здесь мы фиксируем решения, детали и нюансы.
> Обновляется по мере уточнения. Писать сюда можно простым языком.

Дата создания: 2026-06-15
Статус: 🟡 Планирование

---

## 1. Что мы строим (одним предложением)

ИИ-агент, который от лица ресторана общается с гостями (сначала текстом),
бронирует столики, отвечает на вопросы о ресторане и меню, записывает важную
информацию от гостя — и которого можно **настроить под любой ресторан и продать**.

---

## 2. Принятые решения (зафиксировано)

| Вопрос | Решение | Почему |
|---|---|---|
| Канал общения | **Текстовый чат** (сайт/WhatsApp) на старте, голос/телефон — позже | Дешевле и быстрее отладить логику бронирования |
| База бронирования | **Своя лёгкая база + «переходник» (adapter)** на старте; внешняя система (resmio/Quandoo/TheFork) подключается потом без переделки логики | Внешние API требуют партнёрского одобрения (недели). Нельзя блокировать старт |
| Языки | **Немецкий** — первый. Английский — следующий | Гамбург: немецкий обязателен |
| Масштаб | **Один пилотный ресторан**, доводим до идеала, потом масштабируем | Быстрее реальный результат, меньше риска |

Рекомендация по внешней системе (когда будем подключать): **resmio** —
немецкий продукт, есть бесплатный тариф и API, дружелюбен к пилоту.

## 3. Что агент должен уметь

### Ядро (обязательно к запуску — MVP)
- [ ] Понимать запрос гостя на естественном (немецком) языке
- [ ] Создавать бронь: дата, время, число гостей, имя, контакт
- [ ] Знать, какие столы свободны/заняты на конкретное время
- [ ] Учитывать длительность визита:
      - 2–4 человека → 1,5–2 часа
      - более 4 человек → дольше (настраивается)
- [ ] Записывать бронь в базу
- [ ] Отвечать на вопросы по меню
- [ ] Отвечать на типовые вопросы: часы работы, адрес, парковка, можно ли с
      собакой, детское меню, оплата картой, терраса
- [ ] Записывать важную информацию от гостя (аллергии, повод, пожелания)
- [ ] Эскалация: если вопрос сложный/гость недоволен — передать менеджеру

### Важное (вторая волна)
- [ ] Изменять и отменять брони
- [ ] Лист ожидания (waitlist), если мест нет
- [ ] Подтверждения и напоминания гостю (снижает неявки / no-show)
- [ ] Учёт аллергий и диет (веган, без глютена, халяль) — предупреждать кухню
- [ ] Особые поводы (день рождения, годовщина) и пожелания (стол у окна,
      детский стул, доступ для коляски)

### Для бизнеса (почему рестораны платят)
- [ ] Защита от неявок: предоплата/карта для больших компаний и пятницы-субботы
- [ ] Допродажи (вино к столу, праздничное меню)
- [ ] Утренняя сводка для управляющего (брони, гости, пожелания, кому перезвонить)
- [ ] Многоязычность
- [ ] Панель управления для ресторана (меню, часы, столы, просмотр броней)
      без программиста
- [ ] Мультиарендность (один движок — много ресторанов) — основа продаж
- [ ] Соответствие GDPR (защита данных, согласие на запись)

## 4. Этапы (дорожная карта)

1. **Фундамент данных** — база: рестораны, столы, брони, меню, часы.
   Логика «свободно/занято» с учётом длительности визита.
2. **«Мозг» агента в чате (текст)** — научить правильно бронировать и
   отвечать. Дёшево тестировать.
3. **Голос/телефон** — подключаем, когда логика отлажена.
4. **Панель ресторана + многоязычность + напоминания.**
5. **Пилот в одном ресторане** → доводим до идеала → масштабируем и продаём.

Текущий фокус: **Этап 1 + Этап 2** для одного ресторана на немецком.

## 4а. Профиль пилотного ресторана: «60 seconds to napoli»

> Собрано из открытых источников (официальный сайт блокирует автоматический
> доступ, данные взяты из агрегаторов — требуют подтверждения у ресторана).

- **Бренд:** 60 seconds to napoli — отмеченная наградами неаполитанская пиццерия
- **Это сеть, а не одна точка** (важно!). Найдены минимум 3 локации в Гамбурге:
  - Großer Burstah 1-3, 20457 Hamburg (Altstadt/Mitte) — главная
  - Winterhude
  - ещё одна точка («Hamburg 2»)
- **Телефон (Großer Burstah):** +49 40 88305414
- **Часы (предв.):** ежедневно ~12:00–24:00 (уточнить по каждой локации)
- **Кухня:** неаполитанская пицца из дровяной печи; паста, бурата, салаты,
  десерты; есть веган-опции (напр. «Green Mamba Vegan»); сезонные блюда
- **Цены:** пицца ~€12–16,50; ужин ~€20–30 на человека
- **Доставка:** Wolt, Uber Eats
- **Бронирование сейчас:** через restaurant-reservierung.de и AutoReserve
  → это вероятные кандидаты для нашего «переходника» (adapter)

**Вывод для архитектуры:** даже наш первый клиент — это **мультилокация**.
Значит, базу и агента сразу делаем с поддержкой нескольких точек под одним
брендом (но интерфейс настройки оставляем простым). Это удачно совпадает с
будущей мультиарендностью для продажи другим ресторанам.

### Что осталось узнать именно у ресторана (нет в открытых источниках)
- Какую локацию берём пилотом? (рекомендую главную — Großer Burstah)
- Сколько столов и какой вместимости в этой локации? Есть ли терраса/зоны?
- Точная система бронирования (restaurant-reservierung.de или AutoReserve?)
- Полное актуальное меню с ценами и аллергенами (сайт закрыт для автодоступа)

## 6. Словарь терминов (для не-программиста)

- **MVP** — минимально работающая версия, которую уже можно показать гостю.
- **API** — способ, которым две программы «разговаривают» друг с другом.
- **Adapter («переходник»)** — прослойка, чтобы менять внешнюю систему,
  не переписывая логику агента.
- **Мультиарендность (multi-tenant)** — один движок обслуживает много
  ресторанов, у каждого свои настройки.
- **No-show** — гость забронировал, но не пришёл.
- **STT / TTS** — распознавание речи / синтез речи (для будущего голоса).
- **GDPR** — европейский закон о защите персональных данных.
